# Sweet House Web App

## Project Overview
A React-based website for browsing Indian sweets, managing a shopping cart, and placing customer orders.

## Features
- View sweets and prices
- Search sweets
- Add sweets to cart
- Change quantity and calculate total
- Enter customer name, mobile number, and address
- Place orders
- Admin panel to add, edit, and delete sweets
- View customer orders and update order status

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Vite

## How to Run
1. Open the project folder in VS Code.
2. Open Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in Terminal.
